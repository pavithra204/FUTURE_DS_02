# Customer Retention & Churn Analysis

**Future Interns – Data Science & Analytics Internship | Task 2 (2026)**

## Project Overview

This project focuses on analyzing customer retention and churn patterns using the Telco Customer Churn dataset. The goal is to understand why customers leave a service, identify potential churn factors, and provide insights that can help improve customer retention.

## Tools & Technologies

- **Python (Google Colab)** – Data cleaning and analysis
- **Pandas** – Data manipulation and preprocessing
- **Power BI** – Interactive dashboard and data visualization
- **CSV** – Dataset format

## Project Workflow

1. Imported the Telco Customer Churn dataset into Google Colab.
2. Explored the dataset and checked for missing values.
3. Cleaned and preprocessed the customer data using Python.
4. Analyzed customer churn, tenure, contract types, and payment methods.
5. Used the cleaned dataset to create an interactive Power BI dashboard.
6. Presented key metrics and customer churn patterns through visualizations.

## Dashboard Highlights

The Power BI dashboard includes:

- **Churn Rate:** 26.54%
- **Total Customers:** 7,043
- **Churned Customers:** 1,869
- Customer Churn Distribution
- Average Customer Tenure by Churn Status
- Customer Churn by Contract Type
- Churn Rate by Payment Method

## Key Insights

- Overall customer churn rate is approximately 26.54%.
- Customers who churned had a shorter average tenure compared to retained customers.
- Electronic check users showed a higher churn percentage than other payment methods.
- Customer contract types and payment methods provide useful insights into customer retention patterns.
